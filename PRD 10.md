## 10. Functional Requirements       
   ### Location Search          
-The system shall allow users to search buildings and facilities by name                                    -The system shall display matching search results     
-The system shall show the details of selected location                                             
### Campus Map          
 -The system shall display a digital map of Babcock University                                            -The system shall identify key campus locations on the map                                               -The system shall allow users select a location on the map
### Navigation and Directions           
 -The system shall allow users select their starting point and destination                                 -The system shall provide directions between selected locations                                             -The system shall display the direction clearly on the map
### Location Information               
 -The system shall provide information about selected campus buildings                                      -The system shall categorize locations such as cafeteria, lecture halls and likes.
